ATMOSPHERIC LOOPS & SOUND EFFECTS
=================================

To use loops and sound effects in your monologues, place your custom `.mp3` files in this folder. 

Required File Names:
--------------------
- birds.mp3        (Bird Sounds Loop)
- insects.mp3      (Insects & Crickets Loop)
- zen.mp3          (Zen Meditation Loop)
- rain.mp3         (Rainfall Loop)
- wind.mp3         (Gentle Wind Loop)
- waterfall.mp3    (Waterfall Loop)
- beach.mp3        (Gentle Beach Loop)
- page-flip.mp3    (📖 Page Flip SFX - played on scene transitions)

Configuration / Adding Custom Sound Effects:
--------------------------------------------
If you want to add new buttons or rename existing loops, you can edit the configuration registry inside the codebase:

File path to edit:
[src/utils/audioRegistry.ts](file:///g:/My%20Drive/Antigravity/InteractiveVideoCreationTool/src/utils/audioRegistry.ts)

To register a new sound loop:
1. Open `audioRegistry.ts`.
2. Add a new object to the `AMBIENT_SOUNDS` array:
   ```typescript
   { 
     id: 'thunder', 
     name: 'Gentle Thunder', 
     file: '/sounds/thunder.mp3', 
     audio: null, 
     volume: 0.5 
   }
   ```
3. The Soundboard UI will automatically detect the new entry, generate a play button, and route its volume slider through the AudioContext mixer!
